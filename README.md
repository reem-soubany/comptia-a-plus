Exam Tips:
* On my test, the 1st 4-5 questions were PBQs - if you find them too time-consuming, mark them & skip to the multiple choice questions
* Memorize Cold (with flashcards & repetition)
  * Port Numbers (from Core 1) -> You'll see questions like "Which port is used for secure web traffic?"
  * RAM types, pins, voltage, and differences -> Questions like "What’s the benefit of DDR4 over DDR3?" → higher transfer rate & lower voltage
  * Connector types & cable standards: USB, Video, Networking - types, speeds, colors, and their purpose
    * also know differences btwn SATA, M.2, NVMe
  * 802.11 standards, their speed, frequency and which uses MIMO and MU-MIMO
    
  * Command Line Tools (from Core 2) -> know what each do and when to use them. Below are the common ones:
    * ipconfig, ping, tracert, nslookup
    * chkdsk, sfc /scannow, diskpart
    * netstat, net use, tasklist, shutdown
    * dir, cd, mkdir, rd
  * File Extensions & their usage
    * .bat, .sh, .exe, .dll
    * .log, .sys, .msi
    * .iso, .vhd, .img
  * Windows version, their editions & features
    * Windows 7,8,10,11 (basic differences)
    * Focus more on Windows 10
    * Know the minimum CPU/RAM/HDD requirement for each Windows OS
   
  * Some PBQs you might see:
    * Printer troubleshooting
    * Video, projector, display troubleshooting
    * Motherboard layout
